# rail-editor

架空鉄道の路線エディタ。地図をクリックして駅を置くと、駅間距離と所要時間が自動で計算される。

## 使い方

`index.html` をブラウザで開くだけ（地図表示にネット接続が必要）。
GitHub Pages でも開けます: https://matchaudon56.github.io/rail-editor/

- 地図クリックで駅を追加、駅はドラッグで移動できる
- 右のパネルで駅名の変更・並べ替え・削除
- 路線名・色・表定速度・迂回率は上のバーで変更
- 書き出し: YAML（時刻表データ形式）／路線図SVG（Inkscapeで編集可）／JSON
- 作業内容はブラウザに自動保存される
- 起動時のサンプルとして山陽空港線（大都会岡山）が入っている
